
# QaytaTap — Жоғалған заттарды іздеу платформасы

## 1. Жоба туралы

QaytaTap — жоғалған және табылған заттар туралы хабарландыру жариялауға арналған веб-платформа. Жоба адамдарға жоғалған заттарын табуға және табылған заттардың иесін іздеуге көмектеседі.

## 2. Жобаның мақсаты

Жоғалған және табылған заттар туралы ақпаратты бір жерде жинақтау және пайдаланушыларға қажетті затты іздеуді жеңілдету.

## 3. Жобаның өзектілігі

Күнделікті өмірде адамдар жеке заттарын жоғалтып алуы мүмкін. QaytaTap платформасы жоғалған зат туралы ақпаратты жылдам жариялауға және табылған заттар туралы хабарландыруларды қарауға мүмкіндік береді.

## 4. Жобаның негізгі функциялары

- Пайдаланушыны тіркеу және жүйеге кіру
- Жоғалған зат туралы хабарландыру қосу
- Табылған зат туралы хабарландыру жариялау
- Хабарландыруларды қарау
- Заттың атауы, сипаттамасы немесе орналасқан жері бойынша іздеу
- Хабарландыруларды санат бойынша жіктеу
- Өз хабарландыруларын өңдеу және жою

Ескерту: бұл функциялардың кейбірі жобаның даму барысында іске асырылады.

## 5. Сайттың негізгі беттері

1. **Басты бет (index.php)** — хабарландыруларды көрсету және іздеу.
2. **Тіркелу беті (register.php)** — жаңа пайдаланушыны тіркеу.
3. **Кіру беті (login.php)** — пайдаланушының аккаунтына кіру.
4. **Хабарландыру қосу беті (create.php)** — жаңа хабарландыру жариялау.
5. **Хабарландыруларды басқару беті** — хабарландыруларды қарау, өңдеу және жою. Бұл беттер кейін әзірленеді.

## 6. Қолданылатын технологиялар

- HTML — веб-беттің құрылымы
- CSS — веб-бетті безендіру
- JavaScript — интерфейстің интерактивтілігі
- PHP — серверлік бағдарламалау
- MySQL — деректерді сақтау
- XAMPP — жергілікті сервер ортасы
- Git және GitHub — жобаның нұсқаларын сақтау

## 7. Дерекқор құрылымы

Жобада үш негізгі кесте қарастырылған:

- **users** — пайдаланушылар туралы ақпарат
- **categories** — заттардың санаттары
- **reports** — жоғалған және табылған заттар туралы хабарландырулар

Кестелер арасындағы байланыстар ER-диаграммада көрсетіледі.

## 8. Жобаны іске қосу

1. XAMPP бағдарламасын іске қосу.
2. Apache және MySQL серверлерін қосу.
3. Жоба файлдарын `C:\xampp\htdocs\qaytatap1` бумасына орналастыру.
4. phpMyAdmin арқылы `qaytatap_db` дерекқорын ашу.
5. Браузерде `http://localhost/qaytatap1/` мекенжайын ашу.

## 9. Жобаның болашақтағы дамуы

- Пайдаланушының жеке кабинетін жасау
- Хабарландыруларды өңдеу және жою функцияларын қосу
- Қауіпсіздік пен деректерді тексеруді жетілдіру
- Интерфейсті әрі қарай жақсарту

## 10. Автор

Жоба жеке оқу жобасы ретінде әзірленуде.
